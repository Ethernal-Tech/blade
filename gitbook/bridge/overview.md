# Overview

This document describes the design of a built-in **Blade Bridge** aimed at enabling interoperability between the **Blade Ethereum blockchain** and other **Ethereum blockchain networks**.

The Ethereum bridge facilitates the seamless transfer of assets and data across disparate blockchain ecosystems, thereby:

* Enhancing liquidity
* Expanding user capabilities
* Fostering innovation through cross-chain functionalities

The proposed design emphasizes:

* **Security**
* **Efficiency**
* **Scalability**

by integrating:

* Smart contracts
* Decentralized relayers
* Robust cryptographic protocols

## Key Features

* **Secure asset locking and unlocking mechanisms**
* **Reliable data validation**

## Scope

This document provides a comprehensive blueprint of the bridge's architecture, detailing:

* Its components
* Data flows
* Security considerations
* Deployment strategies

The ultimate goal is to enable a **trustworthy** and **efficient** cross-chain interaction platform.

## Supported Token Standards

Blade Bridge supports the following token standards:

* **ERC-20** (including the native token)
* **ERC-721**
* **ERC-1155**
